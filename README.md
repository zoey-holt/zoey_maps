# Zoey Maps for Europa Universalis V

This is a small map mode pack for Europa Univeralis V. Despite the plethora of map modes available in game, I always felt it was lacking a few key ones to show important data. Some ideas I had don't seem possible to mod, but these ones were.

## Population Map Modes

Population capacity in particular is mostly hidden from the default map modes even though it is readily availbe in the code. These map modes show it more transparently as well as just show population for groups of locations more clearly.

- **Population Capacity**
  - Colors locations based on pop cap and shows its value in the tooltip
- **Population Capacity Percentage**
  - Colors locations based on `population / pop cap` and shows both in the tooltip
- **Overpopulation**
  - Population capacity percentage but focused on overpopulated locations only
- **Population (No Migration Arrows)**
  - Same as the default population map mode except with the migration arrows removed
- **Province Population**
  - Colors provinces based on population
- **Area Population**
  - Colors areas based on population
- **Region Population**
  - Colors regions based on population
- **Subcontinent Population**
  - Colors subcontinents based on population
- **Country Population**
  - Colors countries based on population

## Resource Map Modes

I feel there should ideally be a way to create custom map modes in game where you can pick and choose multiple resources to show. However, until that becomes available, these few modded map modes for resource combinations will have to do. I choose these specific resources pairs since they are usually what I'm looking for to fulfill many production methods for common goods.

- **Province has Iron or Coal**
- **Province has Stone or Clay**
- **Province has Gold or Silver**
- **Province has Dyes or Silk**
- **Province has Cotton or Wool**
- **Province has Lumber or Fiber Crops**
